# lab-6
Task 1: Write an Arduino program to blink the external LED once per second. Use
the provided LED and connect a 330 Ω current-limiting resistor in series to protect
the LED.
Task 2: Write an Arduino program that controls two LEDs blinking at different
time intervals. The first LED should blink once or twice every second and remain
off for the same amount of time. The second LED should blink once every two
seconds and also remain off for the same amount of time.
